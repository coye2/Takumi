How it works

  • Takumi runs Sumi 1.1 (the Takumi profile on Bonsai 2 27B) with Takumi's task instructions and context settings.
  • Plain OpenCode runs the same Bonsai 2 27B weights with OpenCode and Ollama defaults and the raw task text.
  • Both use the same OpenCode build and permissions, with web search off. Each run gets 10 minutes.
  • Takumi gets a single agent pass here. Its in-app review loop isn't used.
  • Runs alternate which setup goes first each round, so neither benefits from warm caches or time of day.
  • Raw data: results.json. Tasks and tests: the bench/ folder in the Takumi source.
